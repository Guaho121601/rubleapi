rubleapi.ru

Валютный виджет для сайта и api цб рф в json

rubleapi.ru — настраиваемый валютный виджет для сайтов и api цб рф в json.

Настройте валюты, тему и округление, скопируйте `script`-код и вставьте на сайт.

настроить виджет документация

Что умеет

Курсы ЦБ РФ

Показывает курсы валют ЦБ РФ в удобном формате для сайта.

Один script-тег

Подключается простым embeddable-скриптом без React, Vue и jQuery.

Настройка отображения

Поддерживает выбор валют, light/dark тему и округление значений.

CORS для внешних сайтов

Может работать с внешних сайтов через CORS на основном сервере.

Для кого

  • вебмастера
  • владельцы сайтов
  • туристические сайты
  • информационные проекты
  • разработчики

Пример кода

<script
  src="http://127.0.0.1:3000/widget.js"
  data-api-base="http://127.0.0.1:3000"
  data-symbols="usd,eur,cny"
  data-theme="light"
  data-round="2"
  data-branding="true">
</script>

Api

Публичный json api можно использовать напрямую из своих интеграций.

get /api/rates/latest?symbols=usd,eur,cny
