RubleAPI для сайта

Выберите продукт для сайта: информер валют, конвертер или информер криптовалют

RubleAPI помогает быстро добавить на сайт готовый информер курсов валют, интерактивный конвертер или компактный блок с курсами криптовалют. Ниже три понятных сценария без лишней интеграции.

Сценарий 1

Информер курсов валют

Подходит, если вы хотите показать на сайте готовый блок с курсами валют по данным ЦБ РФ без ввода суммы и без лишних настроек для посетителя.

  • Готовый блок с курсами валют по данным ЦБ РФ.
  • Настройка валют, темы, цветов и размеров.
  • Быстрая вставка на Tilda, WordPress или HTML-сайт.

Сценарий 2

Конвертер валют

Подходит, если посетителю нужно ввести сумму, выбрать валюту и сразу получить пересчёт в рубли или обратно по данным ЦБ РФ.

  • Интерактивный пересчёт прямо на странице сайта.
  • Выбор валют для выпадающего списка.
  • Те же простые шаги установки без отдельной интеграции.

Сценарий 3

Информер криптовалют

Курсы BTC, ETH, USDT и других криптовалют в компактном блоке для сайта.

  • Показ цены в USD и RUB.
  • Отображение изменения за 24 часа.
  • Готовый код для вставки на сайт с автообновлением данных на стороне RubleAPI.
