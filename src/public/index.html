Добавьте курс валют на сайт

Настройте внешний вид виджета, выберите нужные валюты и вставьте готовый код на страницу сайта. Курсы берутся по данным ЦБ РФ.

Как это работает

Выберите валюты

Отметьте те курсы, которые хотите показать посетителям сайта.

Настройте внешний вид

Подберите цвета, тему и оформление под свой сайт.

Скопируйте код

Генератор подготовит готовый код для вставки без ручной настройки.

Вставьте на сайт

Добавьте код на страницу через html-блок или в шаблон сайта.

Показывайте курсы ЦБ РФ

Виджет сам получит данные и отобразит их в аккуратном блоке.
