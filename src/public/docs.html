Установка валютного виджета RubleAPI

Подключите embeddable-виджет одним `script`-тегом, настройте валюты и тему на `/widget` и используйте тот же API ЦБ РФ в json для своих интеграций.

1. Быстрый старт

Выберите настройки на странице /widget, скопируйте готовый script-код и вставьте его на сайт. Виджет сам загрузит курсы через публичный api RubleAPI и отрисуется рядом со script.

  1. Откройте страницу генератора кода по адресу `/widget`.
  2. Выберите валюты, тему, округление и брендинг.
  3. Скопируйте готовый `script` и вставьте его на сайт.
  4. Сохраните страницу и проверьте, что сайт может загрузить `widget.js` и api.

2. Пример script-кода

Ниже базовый пример подключения локального виджета во время разработки.

<script
  src="http://127.0.0.1:3000/widget.js"
  data-api-base="http://127.0.0.1:3000"
  data-symbols="usd,eur,cny"
  data-theme="light"
  data-round="2"
  data-branding="true">
</script>

3. Параметры виджета

Виджет читает настройки напрямую из `data-*` атрибутов у подключенного `script`.

data-api-base

Базовый адрес RubleAPI, откуда виджет возьмёт `widget.js` и api курсов.

data-symbols

Список валют через запятую, например `usd,eur,cny`. Поддерживаются `usd`, `eur`, `cny`, `aed`, `try`, `thb`, `vnd`.

data-theme

Тема оформления виджета. Для mvp доступны значения `light` и `dark`.

data-round

Число знаков после запятой. В генераторе предусмотрены варианты `0` и `2`.

data-branding

Показывать брендинг RubleAPI или нет. Возможные значения: `true` или `false`.

4. Установка на обычный html-сайт

Для обычного html-сайта достаточно вставить `script` в нужное место страницы. Виджет отрисуется рядом с ним автоматически.

<div class="rates-block">
  <h2>Курсы валют</h2>
  <script
    src="http://127.0.0.1:3000/widget.js"
    data-api-base="http://127.0.0.1:3000"
    data-symbols="usd,eur,cny"
    data-theme="light"
    data-round="2"
    data-branding="true">
  </script>
</div>

5. Установка на Tilda

В Tilda добавьте html-блок, вставьте в него готовый `script`-код из генератора, затем сохраните и опубликуйте страницу.

<script
  src="http://127.0.0.1:3000/widget.js"
  data-api-base="http://127.0.0.1:3000"
  data-symbols="usd,eur"
  data-theme="light"
  data-round="2"
  data-branding="true">
</script>

6. Установка на WordPress

В редакторе WordPress добавьте блок Custom HTML или Произвольный HTML и вставьте туда код виджета.

<script
  src="http://127.0.0.1:3000/widget.js"
  data-api-base="http://127.0.0.1:3000"
  data-symbols="usd,eur,cny,aed"
  data-theme="dark"
  data-round="0"
  data-branding="true">
</script>

7. Если виджет не загрузился

Если на странице не появился виджет, проверьте самые частые причины.

  • Backend недоступен.
  • Неправильно указан `data-api-base`.
  • Не выбраны валюты.
  • Нет сохранённых курсов в базе.
  • Браузер блокирует запрос.
  • Сайт кеширует старый код.
Для проверки откройте `http://127.0.0.1:3000/health`, убедитесь, что сервер отвечает со статусом `200`, и посмотрите ошибки в devtools браузера.
