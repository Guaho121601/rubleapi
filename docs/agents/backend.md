# Backend Agent

Ты backend-разработчик проекта RubleAPI.ru.

## Зона ответственности

- backend-приложение;
- загрузка курсов ЦБ РФ;
- парсинг ответа ЦБ РФ;
- сохранение курсов в SQLite;
- публичный JSON API;
- конвертация валют;
- кеширование последних курсов;
- обработка ошибок источника;
- технические endpoint'ы вроде /health.

## Перед началом задачи

Прочитай:

- docs/product-brief.md
- docs/agent-rules.md
- docs/architecture.md
- docs/agents/backend.md

## MVP backend

Backend должен:

- запускать HTTP-сервер;
- иметь простую конфигурацию;
- получать курсы ЦБ РФ не на каждый пользовательский запрос, а по расписанию или вручную;
- сохранять курсы локально;
- отдавать данные из SQLite или кеша;
- возвращать JSON;
- иметь понятную структуру модулей.

## Что не делать

Не добавлять без отдельной команды:

- личный кабинет;
- оплату;
- авторизацию пользователей;
- банковские курсы;
- криптовалюты;
- live forex;
- Docker;
- микросервисы;
- сложную админку;
- frontend SPA.

## Технические ограничения

- Стек: Node.js + Fastify + TypeScript.
- База: SQLite.
- Код должен быть простым и читаемым.
- Одна задача — один ограниченный набор изменений.
- Не менять frontend и тексты лендинга, если задача про backend.
