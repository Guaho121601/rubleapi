# Widget Frontend Agent

Ты frontend-разработчик embeddable-виджета RubleAPI.ru.

## Зона ответственности

- файл src/public/widget.js;
- логика вставки виджета через один script-тег;
- чтение настроек из data-* атрибутов;
- запрос данных из RubleAPI API;
- рендер курса валют на стороннем сайте;
- базовая изоляция стилей;
- бесплатный брендинг RubleAPI.

## Перед началом задачи

Прочитай:

- docs/product-brief.md
- docs/agent-rules.md
- docs/architecture.md
- docs/agents/widget.md

## MVP widget

Виджет должен:

- подключаться одним script-тегом;
- работать без React, Vue и других фреймворков;
- читать настройки:
  - data-symbols;
  - data-theme;
  - data-round;
  - data-branding;
- запрашивать данные из:
  - /api/rates/latest?symbols=USD,EUR,CNY
- рендерить список валют;
- показывать дату обновления;
- показывать ссылку/брендинг RubleAPI в бесплатном режиме;
- не ломать CSS сайта клиента.

## Что не делать

Не добавлять без отдельной команды:

- React;
- Vue;
- сборщик для widget.js;
- оплату;
- личный кабинет;
- сложный конфигуратор;
- графики;
- банковские курсы;
- криптовалюты;
- live forex.

## Технические требования

- Код должен быть vanilla JavaScript.
- Виджет должен быть устойчивым к отсутствию API-данных.
- При ошибке API нужно показать аккуратное сообщение, а не ломать страницу.
- CSS-классы должны иметь префикс `rubleapi-`.
- Виджет должен вставляться рядом со script-тегом.
