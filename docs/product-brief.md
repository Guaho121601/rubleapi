# RubleAPI.ru - Product Brief

## Основной продукт

RubleAPI.ru - это настраиваемый валютный виджет для сайтов и API ЦБ РФ в JSON.

Продуктовая рамка проекта строго ограничена двумя связанными сценариями:

1. Владелец сайта вставляет валютный виджет на сайт через простой JS-код.
2. Разработчик получает курсы ЦБ РФ через JSON API для своей интеграции.

RubleAPI.ru не является платформой для e-commerce-автоматизации, финансовых расчетов или сложных бизнес-сценариев. Базовая ценность продукта - быстро показать актуальные курсы валют ЦБ РФ в удобном для сайта или системы формате.

## Коммерческая модель

Монетизация строится вокруг виджета и API:

1. Бесплатный валютный виджет с брендингом RubleAPI.
2. Платный white-label виджет без брендинга RubleAPI.
3. Платные настройки оформления виджета.
4. API ЦБ РФ в JSON для разработчиков.
5. В будущем - инструкции и готовые интеграционные сценарии для Tilda, WordPress, Bitrix, WooCommerce и OpenCart.

Главная коммерческая гипотеза: пользователи не платят за сам факт доступа к курсам ЦБ РФ, но готовы платить за удобное встраивание, отсутствие брендинга, настройку внешнего вида и удобный API для интеграции.

## MVP

В MVP входят только следующие возможности:

1. Виджет курса валют для встраивания на сайт.
2. Выбор валют, которые отображаются в виджете.
3. Тема оформления виджета.
4. Округление значений.
5. Брендинг RubleAPI в бесплатной версии и возможность убрать брендинг в платной версии.
6. API ЦБ РФ в JSON.
7. Простой JS-код для вставки виджета на сайт.

MVP должен оставаться узким: сначала виджет и API, без расширения в соседние продуктовые категории.

## Что не входит в продуктовую рамку

Не добавлять в продуктовую рамку MVP и ближайших итераций:

- автоматический пересчет товарных цен;
- наценки и скрытые платежи;
- финансовые калькуляторы;
- конвертеры со сложной бизнес-логикой;
- личный кабинет;
- онлайн-оплату;
- банковские курсы;
- криптовалюты;
- live forex;
- маркетплейс обменников;
- мобильное приложение;
- сложную админку;
- AI-функции;
- инвестиционные рекомендации.

## Основная аудитория

- владельцы сайтов;
- вебмастера;
- разработчики;
- интернет-магазины, которым нужно показать курс валют на сайте;
- B2B-компании, которым нужен курс валют в интерфейсе или интеграции.

## Позиционирование

RubleAPI.ru - это сервис с понятной и узкой ценностью: настраиваемый валютный виджет для сайтов и API ЦБ РФ в JSON.

Бесплатная версия решает задачу быстрого размещения виджета с брендингом RubleAPI. Платная версия продает white-label, дополнительные настройки оформления и более удобный сценарий интеграции для разработчиков и бизнеса.
