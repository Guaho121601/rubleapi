# RubleAPI.ru — Product Brief

## Суть проекта

RubleAPI.ru — сервис валютных виджетов и API курсов ЦБ РФ в JSON.

## MVP

В первую версию входит:

1. Бесплатный виджет курса валют с брендингом RubleAPI.
2. Платный виджет без брендинга с настройкой:
   - валют;
   - цветов;
   - округления;
   - источника курса.
3. API ЦБ РФ в JSON для разработчиков.
4. Простой JS-код для вставки на сайт.
5. В будущем:
   - WordPress-плагин;
   - интеграции с Tilda;
   - Bitrix;
   - WooCommerce;
   - OpenCart.

## Не входит в MVP

Не делать в первой версии:

- личный кабинет;
- оплату;
- банковские курсы;
- криптовалюты;
- live forex;
- маркетплейс обменников;
- мобильное приложение;
- сложную админку;
- AI-функции;
- инвестиционные рекомендации.

## Основная аудитория

- владельцы сайтов;
- вебмастера;
- разработчики;
- интернет-магазины;
- туристические сайты;
- B2B-компании, которым нужен курс валют на сайте или в системе.

## Главная гипотеза

Пользователи не платят за сам курс валют. Они могут платить за удобный виджет, отсутствие брендинга, настройки и стабильный API.

## Позиционирование

RubleAPI.ru — бесплатный валютный виджет с брендингом и API ЦБ РФ в JSON. Платная версия убирает брендинг и добавляет настройки.
