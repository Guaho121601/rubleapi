# RubleAPI Agent Rules

## Общие правила

Проект делает один разработчик с ограниченным бюджетом. Решения должны быть простыми, поддерживаемыми и без лишней архитектуры.

## Перед каждой задачей

Codex должен прочитать:

- docs/product-brief.md
- docs/agent-rules.md
- docs/architecture.md, если файл уже создан
- нужный файл роли из docs/agents/

## После каждой задачи

Codex должен:

- показать список изменённых файлов;
- кратко объяснить, что изменено;
- указать, какие тесты запустить;
- не менять файлы вне задачи.

## Запреты

Не добавлять без отдельной команды:

- оплату;
- личный кабинет;
- авторизацию пользователей;
- криптовалюты;
- банковские курсы;
- live forex;
- сложную админку;
- React/Vue для embeddable-виджета;
- микросервисную архитектуру;
- Docker, если его не попросили отдельно.
